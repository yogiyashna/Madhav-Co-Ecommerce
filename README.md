# 🛍️ Madhav & Co.

### Full-Stack E-Commerce Website

A modern full-stack e-commerce platform built with **React, Node.js, Express.js and MongoDB**.

Madhav & Co. provides a complete shopping experience for customers along with a dedicated admin dashboard for managing the platform.

---

## ✨ Features

### 👤 Customer Panel

- 🔐 Register & Login
- 📱 OTP Verification
- 🔎 Product Search & Categories
- 🛒 Cart & Wishlist
- 💳 Checkout & Payments
- 📍 Shipping Address
- 📦 Order History & Tracking
- ⭐ Product Reviews & Ratings
- 👤 Profile Management

### 👨‍💼 Admin Panel

- 🔐 Separate Admin Login
- 📊 Dashboard
- 📦 Product Management
- 🛒 Order Management
- 👥 User Management
- 🏷️ Category Management
- ⭐ Review Management
- 🖼️ Image Upload

---

## 🔑 Login

### Customer

**Login:** `http://localhost:5173/login`

Customers can browse products, manage their cart and wishlist, place orders, make payments and submit reviews.

### Admin

**Admin Login:** `http://localhost:5173/admin/login`

The Admin Panel provides access to:

`Dashboard` • `Products` • `Orders` • `Users` • `Categories` • `Reviews`

---

## 🛠️ Tech Stack

**Frontend**

React.js • Vite • JavaScript • CSS • React Router

**Backend**

Node.js • Express.js • MongoDB • Mongoose

**Authentication**

JWT • bcryptjs

**Services**

Razorpay • Cloudinary

## ⚙️ Run Locally

### Backend

```bash
cd backend
npm install
npm run dev
```
### Frontend

```bash
cd frontend
npm install
npm run dev
```
