# Madhav & Co. - E-Commerce Website

A full-stack e-commerce web application built using React, Node.js, Express.js, and MongoDB.

## Features

### Customer Features

- User registration and login
- Product browsing
- Product details
- Product search and categories
- Shopping cart
- Quantity management
- Wishlist
- Checkout
- Shipping address management
- Cash on Delivery
- Razorpay payment integration
- Order placement
- Order history
- Product reviews and ratings

### Admin Features

- Admin authentication
- Product management
- Add products
- Edit products
- Delete products
- Product image upload using Cloudinary
- Order management
- Update order status

## Tech Stack

### Frontend

- React
- Vite
- JavaScript
- CSS

### Backend

- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication

### Services

- Razorpay
- Cloudinary
